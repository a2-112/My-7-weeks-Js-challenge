# My 7 Week JavaScript script

This is a full record of how I taught myself JavaScript — from reversing a string to fetching real data from an API — over roughly 44 days, entirely self-taught.

I'm sharing this because I remember exactly what it feels like to be stuck at 2am, staring at a bug, with no one to ask. Every function in `script.js` is something I built myself, debugged myself, and commented in my own words while I was still learning it — not after, when it's easy to forget how confusing it actually was.

## Why This Exists

Most practice-problem lists give you a problem and maybe a solution. They don't tell you *why* it works, or walk you through the exact moment something clicks. This is different — every comment in this file is written from inside the confusion, the way I actually understood it, not a polished explanation written after the fact.

If you're self-taught, or learning alone, and stuck on something that feels impossible — I hope seeing my own messy, honest process helps you trust that confusion is part of it, not a sign you're behind.

## How It's Organized

Everything lives in one file, `script.js`, in the order I actually learned it:

- **Week 1 — Strings & Arrays:** reversing strings, counting vowels, FizzBuzz, finding the largest number, palindromes, removing duplicates, finding the most frequent word
- **Week 2 — Objects, Maps & Problem Decomposition:** two sum, grouping by category, flattening arrays, anagrams, chunking arrays, adjacency matrices, character frequency, top 3 words
- **Week 3 — Recursion & Algorithms:** Fibonacci, power functions, binary search, flatten with depth, deep cloning
- **Week 4 — Data Structures:** memoization, Stack, Queue, valid parentheses, linked lists (reverse + find middle), LRU cache, bubble sort, merge sort, sliding window (longest substring)
- **Week 5 — Trees & Graphs:** tree traversal (DFS/BFS), adjacency lists, graph traversal, shortest path
- **Week 6 — Dynamic Programming & Functional JS:** climbing stairs, coin change, longest common subsequence, currying, compose/pipe
- **Final Integration:** a challenge combining recursion + a real tree structure (an org chart, finding total salary and the highest-paid employee)
- **Async JavaScript:** callbacks, promises, `.then()`/`.catch()`, `async`/`await`, `try`/`catch`, and `fetch()` — ending with a working mini quote-generator app

Each function has comments written the way I explain things to myself — plain, sometimes rough, but true to how I actually built understanding of it.

## How To Use This

**Option 1 — Read it.** Open `script.js` and read the comments before the code. Try to guess what a function does from its comment before scrolling to see the implementation.

**Option 2 — Practice it.** Cover the function bodies, keep just the function name and the test calls at the bottom, and try to rebuild each one yourself from scratch. Then compare against mine.

**Option 3 — Run it.** Open `index.html` in a browser, open the developer console, and watch every result log in order.

## A Note On Process

I didn't get any of this on the first try. Nearly every function here went through real bugs — wrong loop directions, off-by-one errors, mixed-up variable names, misunderstood return values — before it worked. If you're struggling with something similar, that's not a sign you're doing it wrong. That's just what learning looks like.

Good luck. You've got this. 💙
